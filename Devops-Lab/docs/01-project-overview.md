# Project Overview

## Objective

To design, implement and manage a production-style CI/CD platform using enterprise Linux technologies.

## Scope

The project covers:

- Linux Administration
- Git
- Jenkins
- Docker
- Kubernetes
- Helm
- Security Scanning
- Monitoring
- GitOps

## Out of Scope

- High Availability
- Multi-region deployment
- Production cloud networking

These will be implemented in future phases.
