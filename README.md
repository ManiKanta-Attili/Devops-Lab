# Enterprise CI/CD Platform using RHEL 10

## Project Overview

This project demonstrates the implementation of an enterprise-grade CI/CD platform using Red Hat Enterprise Linux 10, Jenkins, Docker, Kubernetes, Helm, SonarQube, Trivy, Prometheus and Grafana.

The objective is to simulate a production DevOps environment running on local VirtualBox virtual machines and later migrate the same architecture to AWS EC2.
